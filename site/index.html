A SIMPLE WAY IN

Your first hello.
Four clear steps.

This is the guided setup plan—not a functioning sign-in or connection flow. The fictional demo above works today, with no account.

  1. 01

    Sign in

    Planned: your Poki identity, with clear service terms and permissions before you join.

  2. 02

    Choose a connection

    Browse the guides below. Only link a website, channel or coding host you choose.

  3. 03

    Follow a short guide

    See the exact access, prove ownership and accept a contact. No tracking around the internet.

  4. 04

    Test a little hello

    Preview and approve one test with your chosen recipient. Disconnect whenever you want.

Instagram DMsPlanned · needs Meta configuration+
  1. Future setup: link an eligible Instagram account to the company-managed service.
  2. Review the exact messaging scopes; provider app, webhook configuration and required approvals must be completed first.
  3. Verify ownership and test only with an explicitly participating recipient, within current provider rules.

Disconnect must revoke the link and stop delivery. No Instagram app, OAuth grant or message sending is configured here.

TelegramPlanned · needs a bot and backend+
  1. Future setup: choose to start the Poki bot and verify the link to your own identity.
  2. Review the bot/chat access. Bot credentials stay on the hosted service, never in this page.
  3. Accept a contact and approve one test hello; user initiation and platform rules still apply.

Disconnect must unlink the account and stop routing. No bot or token is configured by this demo.

CodexExperimental reference · host setup unverified+
  1. Review the existing local MCP reference and its limited read/prepare credential.
  2. Choose a specific inbox; review tool and file access before any manual configuration.
  3. Test an on-demand inbox read and separately approved hello. Remove the MCP connection and revoke its credential to disconnect.

Protocol tests exist; stock host onboarding and automatic animated chat delivery are not verified.

Claude CodeCandidate · no Poki integration verified+
  1. Future evaluation: confirm the supported MCP setup for the target host/version.
  2. Use a scoped Poki connector only after permission review; no unrestricted chat or file access.
  3. Test read/prepare/approval and verify removal plus token revocation.

This is a candidate, not a working connect button. No host configuration is changed.

OpenCodeCandidate · no Poki integration verified+
  1. Future evaluation: verify the exact product/version and its MCP contract.
  2. Review the limited connector scopes before any local or remote setup.
  3. Test one chosen inbox, explicit approval and disconnect. Never infer support from the host name alone.

No OpenCode connection is installed or enabled. Other uncertain host names are not advertised as supported.

WhatsApp is outside this MVP. No sign-in, OAuth, webhooks, social messages or hosted account service is active. Future service policy requirements are a draft, not approved company terms.
