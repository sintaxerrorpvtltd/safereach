# Community conduct

Everyone is welcome to contribute to this project maintained by Syntax Error Pvt
Ltd. Be patient with new contributors, explain feedback clearly, credit others,
and discuss technical disagreements respectfully.

Harassment, discrimination, threats, doxxing, unsolicited contact and publishing
private information are not acceptable. Do not pressure anyone to pair, respond
to a poke or share sensitive data. Respect a decline, mute or disconnect.

Maintainers may moderate content, close disruptive discussions or restrict access
to protect participants. For a conduct concern, contact a repository maintainer
through an available private GitHub channel, or request a private channel without
posting personal details. Security concerns follow SECURITY.md.
